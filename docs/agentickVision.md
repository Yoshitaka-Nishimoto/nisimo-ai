「Antigravity（おそらく特定のフレームワークやプロジェクト、あるいは自律型エージェントの総称と推察します）」において、**「画像からスキル（`.md`形式の定義ファイル）を自動生成する」**というプロセスは、Agentic Visionの最も得意とする分野です。

A4のラフ画（`画面デザイン.jpg`）から、エージェントが実行可能な`画面デザインskill.md`を生成するための具体的な手順と、AIに与えるべき指示の構造を解説します。

---

### 全体ワークフロー
1.  **入力:** スマホで撮影した「画面デザイン.jpg」
2.  **Vision Agentによる解析:** 構成要素（ボタン、入力欄、遷移）の抽出
3.  **マッピング:** デザイン意図を「スキル（機能）」へ変換
4.  **出力:** `画面デザインskill.md` の書き出し

---

### 手順 1：画像の最適化（前処理）
スマホで撮った写真をAI（GPT-4oやClaude 3.5 Sonnetなど）に投げる前に、以下の点を確認します。
*   **ファイル名:** `screen_v1_layout.jpg` など、役割がわかる名前にする。
*   **解像度:** 小さな文字（12px相当）が判読できるか、スマホ上でピンチインして確認。
*   **正規化:** 可能であれば、Microsoft Lens等のアプリで「ドキュメント（平面的）」に補正した状態で保存してください。

---

### 手順 2：Vision Agentへのプロンプト構成
「画像をただ説明して」と言うのではなく、**「スキル定義ファイルを作れ」**というエンジニアとしての役割を与えます。

**【AIへの指示（プロンプト）の例】**
> あなたは優秀なフルスタックエンジニアおよびエージェント設計者です。
> 添付された「画面デザイン.jpg」を解析し、この画面を実現するためのエージェント用スキル定義ファイル（Markdown形式）を作成してください。
>
> **出力ファイル名:** 画面デザインskill.md
>
> **解析項目:**
> 1. 画面の主要コンポーネント（ヘッダー、入力フォーム、ボタン等）
> 2. ユーザーのアクション（クリック、入力）
> 3. アクションに伴う業務ロジック（どのAPIを叩くか、どの画面へ遷移するか）
> 4. バリデーションルール（ラフに記載された注釈から読み取ること）
>
> **スキル定義のフォーマット:**
> - # Skill Name
> - ## Description (何をするための画面か)
> - ## Components (要素一覧)
> - ## Logic/Flow (業務フロー図から読み取った処理手順)
> - ## Constraints (制約事項)

---

### 手順 3：スキルの構造化（.mdの中身の設計）
生成される `画面デザインskill.md` は、後で他のエージェント（Code Agentなど）が読み取れる形式である必要があります。具体的には以下のような内容が含まれるようにVision Agentに指示します。

```markdown
# 画面デザインスキル: [画面名]

## 1. 概要
- **目的**: ユーザーが〇〇を登録するためのインターフェース
- **ターゲット**: 社内管理者

## 2. 視覚的構成要素 (Vision Analysis)
- [ ] テキスト入力: 商品名（12px注釈: 必須入力）
- [ ] ドロップダウン: カテゴリ選択
- [ ] 実行ボタン: 「登録」 (青色、右下配置)

## 3. 業務ロジック (Flow Analysis)
1. ユーザーが「登録」をクリック
2. 入力値のバリデーションを実行
3. `POST /api/v1/products` へデータを送信
4. 成功時、完了ダイアログを表示し、一覧画面へ遷移

## 4. 補足（ラフ画からの抽出）
- 引き出し線に記載された「※未入力時は赤枠」をバリデーションルールとして採用。
```

---

### 手順 4：Agentic Visionの実装（Python等のコードで行う場合）
もしこれを自動化（Agenticに実行）したい場合は、以下のようなフローを組んでください。

1.  **Vision Toolの呼び出し:**
    `vision_agent.process_image("画面デザイン.jpg")`
2.  **マークダウン抽出:**
    AIが画像からテキストと構造を抽出。
3.  **検証 Agent:**
    「この.mdファイルは、元の画像にある『業務フロー』の矢印をすべて網羅しているか？」を別のVisionプロンプトでチェックさせる（セルフチェック機能）。
4.  **ファイル保存:**
    `save_to_file("画面デザインskill.md")`

---

### 成功させるための「ラフ画」のコツ
Vision Agentに正確な`.md`を作らせるために、ラフ画に以下の**「マーカー」**を書き込んでおくと精度が上がります。

*   **[ ] (四角):** 入力フィールドやチェックボックス
*   **< > (山括弧):** ボタン要素
*   **丸囲みの数字 (①②③):** 処理の順番
*   **点線:** 画面遷移（「→」の先に遷移先画面名を記載）
